2.1 促销占比上涨 +4.86pp，与什么有关

把促销折扣拆成 销量 × 单件促销折扣：

归因路径金额占增量
销量增长带动（3,600 → 8,830 件）+$85,92717%
单件促销折扣上升（$16.4 → $62.8/件）+$409,79483%
结论：83% 的促销增长来自「每件货补贴更多」，只有 17% 来自卖得更多。
单件促销折扣 3.8 倍（$16.43 → $62.84）。同样卖一件货，多补贴 $46.4。

四个真实原因

  • ① 链接数翻倍（836 → 2,792，+234%）+ 新品占比 1/3~1/2 — 新品没排名没评论，破零只能靠促销。 （"新品占比"用BI字段 有销售sku新品占比，其"新品"定义待IT确认）
  • ② 提了价，然后用折扣把价格还回去 — 名义售价 +$96（+11.8%），单件促销 +$46.4，净到手只涨 $50（+6.2%）。提价的 48% 被折扣吃回去了。
  • ③ 渠道结构变化 + PO 费率失控 — PO 促销占比 1.81% → 9.35%（5.2×，全渠道涨幅最大）；FBA 销售额占比 10.3% → 20.0%。
  • ④ 平台大促节奏（折扣通胀） — 202626 大促周促销折扣环比 +153%，但 BD 销量 −11%、优惠券销量 −67%。

4.1 ⭐ 关键问题：库存一路下降，促销却在加码

图7 促销占比（整体口径·US37+VC1）vs 三渠道在售率 —— 7月促销冲顶的同时，三条在售率曲线同步掉头向下
把库存、库销比、在售率、促销四条线放在一起，矛盾就出来了：
  • 5→7月：FBA 可售库存 1,044 → 724 → 402 件（腰斩再腰斩），FBA 库销比 3.70 → 1.90 → 0.97
  • 同期促销占比反向走高：5.44% → 8.37% → 11.08%
  • 在售率、有货率同步下探：FBA 在售率 −9.04pp、DF −11.77pp、VC-PO −9.75pp；FBA 有货率 −7.91pp
  • 毛利率一路塌到 12.70%
即：库存越薄，促销越猛。这不是"清库存"，而是"清库存的同时还在打折"——货卖完了、钱赔了、排名也没保住（§5.3 有25个ASIN打完折8月直接零动销）。
🟢 8月是可以收住的 —— 但代价很明显
  • 促销占比 11.08% → 2.58%（−8.50pp），推广同步回落，全渠道毛利率修复到 20.73%（+8.03pp） → 说明力度是可控的
  • 但8月销量 937 vs 7月 1,873（腰斩），两个原因叠加：
      ① 断货拖累：FBA 可售仅剩 251 件，FBA 在售率继续掉到 33.45%、有货率 28.06%——没货可卖
      ② 促销与推广同时退出：8月促销 $21,536（7月 $185,688 的11.6%）、广告 $15,256（7月 $59,312 的25.7%）——推力也撤了
  • 所以8月的"健康"是收缩换来的，不是效率提升换来的。真正的目标应该是"7月就收住、且库存不断"。

5.4 🔍 为什么7月没有停止促销？（五个原因）

① 旺季排名保卫战：退出即掉位
7月正值品类旺季，多个主推ASIN已进入小类前10–前50（§8）。此时收促销意味着主动放弃刚在6月大促中买到的排名位置—— 而排名一旦掉落，需要更高成本才能买回来。所以运营侧的理性选择是"继续投，稳出单，保排名"。
② 促销力度的"棘轮效应"：只升不降
折扣一旦做过深，就形成了历史价格锚点：低折扣设置不出划线价、优惠券也提报不了比上次更低的力度。 结果是"想降降不下来"——要么维持原力度，要么牺牲链接的促销资格，形成单向棘轮。2026年已有 241个ASIN被锁死在 ≥10%。
③ 提报周期与库存变化不同步（流程性原因）
促销按批次提报（如 7.18–7.31 一批），提报时库存尚未见底，执行期内库存才快速消耗。 系统里没有"执行期内库存跌破阈值 → 自动中止"的机制，所以提报决策和执行现实之间出现了时间差。
④ 库销比用的是全链路口径，掩盖了单渠道缺货（指标性原因）
全链路库销比7月是 7.41（看着并不紧张），因为分子把海外仓、本地仓、在途货全算进去了； 真正缺货的 FBA 单渠道库销比是 0.97。决策看的是加权后的"总量"，而缺货发生在结构里。
⑤ 责任分散：库存预警与促销决策分属两侧，缺联动
库存监控/补货在供应链侧，促销提报在运营侧，两侧各有指标但没有交叉校验的动作—— "看到库存低"和"停掉促销"之间缺少一道强制流程。8月能收住，说明能力是有的，缺的是触发规则而非意愿。

需要建立的机制（对应策略卡）

  • 硬闸门：提报前按渠道级库销比逐SKU校验，库销比<2 直接拦截，不给人工override
  • 执行期熔断：促销进行中每日回检，当日可售=0 或库销比跌破1 → 自动暂停该SKU促销
  • 口径切换：促销决策一律使用渠道级库销比，禁用全链路数
  • 棘轮破解：新促销一律从低力度起步（首次≤5%），避免形成高锚点

5.5 监控失效的四个环节

  • 口径问题：只看全链路库销比（7月 7.41，看着"不高"），看不到 FBA 已经 0.97
  • 渠道混算：在售率用三渠道加权混合数（1月33.17%），看不到 FBA 40.82% vs DF 54.65% 的分化
  • 提报流程：促销按批次批量提报，未逐SKU校验库存，执行期无熔断
  • 无预警机制：没有"库销比跌破阈值→自动暂停促销"的规则

9.4 四个核心问题

问题① 库存监控失效 —— 已断货，促销没停
口径错：促销决策看的是全链路库销比（7月 7.41，看着不紧），而真正缺货的 FBA 单渠道是 0.97； 在售率看的是三渠道加权混合数，掩盖了 FBA 40.82% vs DF 54.65% 的分化。
流程缺：促销按批次提报、无执行期熔断——"提报时库存够、执行期库存见底"这个时间差没有任何机制兜住。
后果：55 个ASIN在海外仓=0时仍在跑折扣；25 个ASIN打完折8月直接零动销。
问题② 促销力度"棘轮效应" —— 只升不降
折扣一旦做深就形成历史价格锚点：低折扣设置不出划线价、优惠券也提报不了比上次更低的力度。 2026年已有 273 个ASIN被锁死在 ≥10%，想降只能牺牲促销资格。
这是"为什么7月没停"的结构性原因之一——不是不想停，是停不下来。
问题③ 效率持续下滑，推广已成为毛利润的最大消耗项
每 $1 推广换来的毛利润 −36%；促销占毛利润 37.4%、推广占毛利润 52.8%。
其中 PO 渠道的促销吃掉了 49.5% 的毛利润（DF 31.5% / FBA 32.9%）——花掉的几乎和赚到的相当。
问题④ 结构失衡：最该保库存的渠道花得最不值
PO 促销占比 9.35%（涨幅 5.2× 全场最大）、促销占毛利 49.5%，但 PO 是 VC 店铺、促销自主可控性最低； FBA 库存最薄（库销比 1.17）、在售率最低（33.45%），却还在跑 5.55% 的促销费率。
同时腰部品牌（KAX/MARSFLUX/PHILTOP/Suride/SIZZER）销量 −71%、费率降到 0.3–3.6%，处于"既没投、也没量"的悬空状态。

整个决策分 5 层：先定年度总额天花板，再逐SKU过 4 道关。任何一关不通过，就不投或降档。

"整体促销占比应该定多少、怎么定？"——两条腿：
  • 第一条腿 · 财务倒推：促销占毛利润 ≤25% → 促销占比上限 = 25% × 毛利率(18.33%) = 4.58%，取整 5.0%
  • 第二条腿 · 分渠道校准：各渠道上限 = 25% × 该渠道毛利率 → DF 4.80% / FBA 4.21% / PO 4.72%， 再按库存厚薄修正：库存最厚的 DF 上浮、库存最薄的 FBA 下调、VC自主性最低的 PO 要求最严
  • 加权校验：52.3%×5.5% + 27.7%×4.5% + 20.0%×3.0% = 4.72% ≤ 5.0% ✓
